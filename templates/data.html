Mohammad, Thabtah, and McCluskey published UCI dataset 327. That file stores 30 engineered features for 11,055 websites. It does not store the URL string, so this workbench cannot score it.

Related public file

High-risk PhishTank URLs, 2022

Korkmaz, Kocyigit, Sahingoz, and Diri collected 36,173 phishing URLs and 51,316 legitimate URLs from PhishTank, for 2006–2021. The legitimate rows are addresses people submitted as suspicious and that voters later marked not phishing. The file also stores page content. This workbench does not open pages, so it does not score that content.

One address from that pattern is https://www.paypal.com/cgi-bin/webscr?cmd=3D_login-run. The host is the real PayPal domain, which is why a brand check alone says it is fine. The query still contains =3D. Email encodes an equals sign as =3D, so this is the raw form of cmd=_login-run, the login command copied in phishing mail. The same command on the real host without =3D stays “Not phishing.” A brand domain written in the path of a different host, such as /www.paypal.com/cgi-bin/webscr on another site, is a separate mismatch.

High-Risk URL and Content Dataset. Korkmaz, Kocyigit, Sahingoz, and Diri, Elektronika ir Elektrotechnika, 2022.
